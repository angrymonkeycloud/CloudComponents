Google Maps JavaScript API check

Loads the map the way the BluSky app will and calls what the port needs: the map itself, satellite imagery, the Geocoder and Places (New). Your key is used only by this page, in your browser, and is not stored or sent anywhere but Google. Open this file through the same origin your key allows (for the MAUI app that is https://0.0.0.1); to try a referrer-restricted key from your machine, serve the file from a host that key allows, or use a temporary key restricted to http://localhost:*/*.
